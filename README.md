## 使用（三步）

1. 解压到任意位置（该目录即「运行时目录」）
2. 双击 DSH-Pilot.exe（或桌面「DSH 启动」）→ 首次运行自动引导
3. 需要时（可选，管理员）：托盘「系统服务设置 → 注册服务」

- 环境要求：**Windows 10 / 11 x64**；主程序走官方 npm 包时只需 Node.js
- 详细说明在程序内：托盘 **关于与帮助 → 帮助手册（MANUAL）**
