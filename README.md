> 本仓库只放**成品**（发布包）；源码不在本仓库、不对外提供。
> 本工具是 **DeepSeek Harness 的辅助管理套件（管理与运维面板）**，不是 Harness 本体，也不是桌面入口——不提供对话界面、不内置模型、不打包运行时。
> ⚠️ **第三方 · 非官方**：本工具由社区开发者独立维护，**不是 DeepSeek 官方 / Harness 官方团队出品**。
> 与官方桌面版的分工：官方桌面版是**用** DSH 的图形客户端；本工具是**管** DSH 的运维面板（系统服务不登录自启 / 双通道主程序版本 / 换通道安全升级与快照回退 / 分级清理与诊断）。本工具不驱动官方桌面版，也不能用它升级官方桌面。
> 同一份成品同步到多个公开站点，内容完全一致（同一个 zip、同一个 SHA256）。

## 能力概览

- **托盘驻留**：右键完整菜单 + 左键快捷菜单，悬浮提示一眼看当前跑的是哪个 DSH（模式 · 版本 · 地址）
- **双通道主程序**：官方 npm 预构建包 与 源码构建 并存，一个配置键切换
- **对向副本安全升级**：只更新非运行中的那份主程序，不停当前服务链；正式 / 预览 / 测试三条版本线
- **一键回退**：环境快照 + 失败回退；起不来先只读诊断（救砖体检），再回到已知可用状态
- **无人值守**：可注册 Windows 服务 `DSHWeb`，不登录也跑；也可只跑服务、不出托盘图标
- **分级清理**：旧版本 / 构建暂存 / 历史日志 / 已删会话的投影缓存残留，分级勾选、执行前二次确认

## 与官方桌面版的分工（互补，不冲突）

| 维度 | 官方桌面版 | DSH-Pilot |
|---|---|---|
| 是什么 | 官方 Electron 图形客户端 | Windows 管理与运维面板（单 exe） |
| 谁在用 | 只想用起来、不碰命令行的人 | 把 DSH 当服务/基础设施跑的人 |
| 开机自启 | 没有（仅登录会话内托盘） | 可注册 Windows 服务，不登录也跑 |
| 升级与回退 | 整体换安装包、禁自动降级 | 对向副本升级 + 失败回退 + 快照回退 |
| 出问题 | 崩溃恢复 / 重装 | 救砖体检 → 快照回退 → 清理 → 诊断包 |

> 一句话选型：只想有个窗口用 DSH → 官方桌面版；要无人值守常驻、自己掌控版本并能一键回退 → DSH-Pilot。

## 使用（三步）

1. 解压到任意位置（该目录即「运行时目录」）
2. 双击 DSH-Pilot.exe（或桌面「DSH 启动」）→ 首次运行自动引导
3. 需要时（可选，管理员）：托盘「系统服务设置 → 注册服务」

- 环境要求：**Windows 10 / 11 x64**；主程序走官方 npm 包时只需 Node.js
- 详细说明在程序内：托盘 **关于与帮助 → 帮助手册（MANUAL）**
- 这是**未签名**程序：SmartScreen 提示「未知发布者」时点「更多信息 → 仍要运行」。
